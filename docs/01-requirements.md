# 01. 개요와 요구사항

근거 자료: 팀 기획 노트(2026-11-14 사진), CP1 보고서(2026-11-03), 배포 목표(많은 사람이 설치해 써 보게 한다).

## 1. 대상 앱

플래닝펫은 일정 관리와 반려동물 키우기를 합친 Java Swing 데스크톱 앱이다.
사용자가 할 일을 해내면 포인트와 경험치를 얻고, 그것으로 고양이를 키우고 방을 꾸민다.

## 2. 특징과 기존 앱 비교

| 앱 | 하는 일 | 플래닝펫과 다른 점 |
|---|---|---|
| Google 캘린더 | 일정 기록과 알림 | 해낸 일에 대한 보상이 없다 |
| Habitica | 할 일을 RPG 퀘스트로 바꾼다 | 전투와 파티 중심이라 익힐 것이 많다 |
| Forest | 집중하는 동안 나무가 자란다 | 일정 관리 기능이 없다 |
| Finch | 자기관리 목표를 하면 펫이 자란다 | 모바일 앱이고 날짜와 시간이 있는 일정 관리가 중심이 아니다 |

플래닝펫만의 특징:

- **아침 브리핑**: 컴퓨터를 켜면 펫이 오늘 할 일을 알려 준다.
- **일정과 성장의 연결**: 할 일을 체크하면 성취도 막대 위를 고양이가 걸어가고 레벨이 오른다.
- **데스크톱, 오프라인**: 공부하고 과제하는 노트북에서 계정 없이 바로 쓴다.

## 3. 이해관계자

| 이해관계자 | 원하는 것 |
|---|---|
| 사용자 (20대 대학생, 취준생) | 해야 할 일을 놓치지 않고, 해낸 만큼 보상받고 싶다 |
| 배포로 만날 일반 사용자 | 설치가 쉽고, 업데이트해도 데이터가 남아 있기를 바란다 |
| 팀 (3명) | 역할(Model, View, Controller)대로 나눠 만들 수 있고 학기 안에 끝나는 범위 |
| 교수 | 수업 내용(요구사항, 유스케이스, UML, Swing MVC)을 적용한 설계 |

## 4. 사용 장면

- **S-1 아침**: 수업 전에 노트북을 켠다. 플래닝펫이 뜨고 고양이가 오늘 할 일과 마감이 가까운 과제를 알려 준다. 출석 보상 +20P를 받고 연속 접속 일수가 하나 오른다.
- **S-2 낮**: 과제 마감 전에 알림이 온다. 과제를 내고 체크하면 포인트를 받고, 고양이가 성취도 막대 위를 한 칸 걷는다.
- **S-3 저녁**: 일정관리 화면에서 내일 할 일을 넣는다.
- **S-4 주말**: 모은 포인트로 상점에서 쿠션을 사서 방에 놓는다. 통계 화면에서 이번 주에 해낸 일을 본다.

S-1의 브리핑과 S-2의 막대는 노트에 있다. 장면 사이의 순서와 세부(마감 전 알림, 주말 통계 등)는 노트를 이어 붙여 만든 것이다.
