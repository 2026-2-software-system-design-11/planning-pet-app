# 캐릭터 창

본 구현(`src/`)에서 캐릭터 창을 만드는 일을 한곳에서 보는 쪽 안내다. 화면 설계는 [05 캐릭터 창](../05-ui-design.md), 옮기는 기록은 [docs/porting/character.md](../porting/character.md)에 있다.

## 무엇인가

고른 펫을 돌보고 꾸미는 창이다(D-47, D-58). 홈 펫 카드를 누르면 상태 탭으로, 나의 방 펫 패널의 장신구 칸이나 "{이름} 꾸미기"를 누르면 꾸미기 탭으로 열린다(D-80, D-83, D-93). 메인 창 위에 뜨는 모달 `JDialog`이고 제목은 "캐릭터"다.

부분:

- 왼쪽: 펫 탭(펫마다 하나), 방 그림 위의 큰 펫과 양옆 화살표, 자세 다섯 칸(앉기, 자기, 기지개, 밥 먹기, 노래)
- 오른쪽: 이름과 "이름 변경" 단추, 레벨과 친밀도 알약, 경험치 막대, 성장 단계, 상태와 꾸미기와 정보 탭, "꾸미기 적용"
- 물음 창 둘: 꾸미기 적용 확인 창, 이름 변경 창

## 덮는 유스케이스와 06 절

- 유스케이스: UC-21 고른 펫 바꾸기(펫 탭, 화살표), UC-22 펫 꾸미기와 자세 고르기, UC-23 펫 이름 바꾸기
- 06 절: 27번 친밀도(값을 그리는 몫), 28번 `applyWear`, 30번 `step`, `rename`, `pose`
