# 06. 함수 명세

유스케이스([02-usecases.md](02-usecases.md))와 결정([decisions.md](decisions.md))을 코드의 함수로 옮긴다. 형식은 개인과제 CP3 양식의 FUNCTION SPECIFICATION(시그니처, 입력, 출력, 하는 일)에 쓰는 곳, 오류, 검사 표를 더했다.

## 읽는 법

- 검사 표의 한 줄은 JUnit 테스트 하나다. 테스트 이름에 검사 번호(예: `T-DAY-1`)를 넣는다. 만든 앱이 이 표를 모두 통과하면 이 명세대로 만든 것이다.
- 지금 시각은 주입한 `java.time.Clock`에서 얻는다. 표의 시각은 운영체제 시간대의 시각이다.
- 표의 날짜는 2026년이다. 2026-11-16은 월요일이다.
- "오늘"은 앱 날짜(D-15)다. 포인트는 P, 경험치는 "경험치 N"으로 적는다.
- 패키지는 `planningpet.model`(데이터와 규칙), `planningpet.store`(저장), `planningpet.app`(화면과 Model을 잇는 Controller), `planningpet.ui`(Swing)다. 클래스 사이의 관계와 저장 파일 형식은 07에서 그린다.

## 데이터

검사 표가 가리키는 값이다. 07의 클래스 다이어그램은 이 값을 빠짐없이 담는다.

| 대상 | 값 | 뜻 |
|---|---|---|
| `Task` | `id` | 바뀌지 않는 번호(UUID 문자열) |
| | `seq` | 넣은 순. 새 일정마다 1씩 늘고 고쳐도 바뀌지 않는다 |
| | `kind` | `TASK`(할 일) 또는 `FIXED`(고정 일정, D-16) |
| | `title`, `date`, `startTime`, `durationMinutes`, `memo` | 제목, 날짜, 시작 시각(없으면 `null`), 걸리는 시간(분), 메모 |
| | `seriesId` | 매주 반복으로 만든 사본끼리 같은 번호. 반복이 아니면 `null`(D-17) |

## 1. `LocalDate AppDay.of(LocalDateTime time)`

시각이 속한 앱 날짜를 돌려준다.

- **쓰는 곳**: "오늘"이 필요한 모든 곳(UC-01, UC-02, UC-07, UC-09, UC-13)
- **입력**: 시각
- **출력**: 앱 날짜
- **하는 일**: `time.minusHours(4).toLocalDate()`(D-15)

| 검사 | 하는 것 | 결과 |
|---|---|---|
| T-DAY-1 | 11-16 03:59 | 11-15 |
| T-DAY-2 | 11-16 04:00 | 11-16 |
| T-DAY-3 | 11-16 23:59 | 11-16 |
| T-DAY-4 | 2027-01-01 03:00 | 2026-12-31 |

## 2. `List<FieldError> TaskDraft.validate()`

일정 입력 창에 쓴 값이 저장할 수 있는 값인지 본다.

- **쓰는 곳**: 일정 입력 창의 저장(UC-03, UC-05), 빠른 추가(UC-04)
- **입력**: `TaskDraft`(종류, 제목, 날짜, 시작 시각, 걸리는 시간, 메모, 반복 끝 날짜). 반복을 고르지 않았으면 반복 끝 날짜는 `null`이다.
- **출력**: 잘못된 칸과 문장의 목록. 칸 순서(제목, 시작 시각, 걸리는 시간, 메모, 반복)로 담는다. 비어 있으면 저장할 수 있다.
- **하는 일**: 제목은 앞뒤 공백을 지운 뒤 잰다. 날짜는 제한이 없다(지난 날짜도 된다). 아래 표 밖의 값은 모두 통과한다.

| 검사 | 하는 것 | 결과 |
|---|---|---|
| T-VAL-1 | 제목 "  과제  ", 할 일, 30분 | 오류 없음. 저장되는 제목은 "과제" |
| T-VAL-2 | 제목 "   " | 제목: "제목을 써 주세요" |
| T-VAL-3 | 제목 101자 | 제목: "제목은 100자까지예요". 100자는 오류 없음 |
| T-VAL-4 | 할 일, 시작 시각 없음 | 오류 없음 |
| T-VAL-5 | 고정 일정, 시작 시각 없음 | 시작 시각: "고정 일정은 시작 시각이 있어야 해요" |
| T-VAL-6 | 시작 09:05 | 시작 시각: "10분 단위로 정해 주세요" |
| T-VAL-7 | 시작 23:30, 30분 | 오류 없음(끝 24:00) |
| T-VAL-8 | 시작 23:30, 40분 | 시작 시각: "하루 안에 끝나야 해요" |
| T-VAL-9 | 걸리는 시간 0, 25, 730 | 각각 걸리는 시간: "10분부터 720분까지, 10분 단위예요". 10과 720은 오류 없음 |
| T-VAL-10 | 메모 1001자 | 메모: "메모는 1000자까지예요" |
| T-VAL-11 | 할 일에 반복 끝 날짜 | 반복: "반복은 고정 일정만 할 수 있어요" |
| T-VAL-12 | 고정 일정 11-16, 반복 끝 11-15 | 반복: "끝 날짜가 시작 날짜보다 앞이에요" |
| T-VAL-13 | 고정 일정 11-16, 반복 끝 2027-05-10(25주 뒤) | 오류 없음(26번). 2027-05-17이면 반복: "반복은 26번까지예요" |
| T-VAL-14 | 제목 "", 걸리는 시간 25 | 제목, 걸리는 시간 순서로 오류 두 개 |
