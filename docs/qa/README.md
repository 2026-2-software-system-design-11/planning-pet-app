# QA 정리

[user-flows.md](../user-flows.md)의 흐름 32개를 프로토타입에서 돌린 결과다. 자세한 확인 결과는 `prototype/qa.sh`가 만드는 [prototype-flows.md](prototype-flows.md)에 있다. 흐름으로 확인할 수 없는 06 검사 줄은 [manual-checklist.md](manual-checklist.md)에 있다.

## 1. 결과

- 실행: `prototype/qa.sh`(JDK 21, 창을 띄우지 않음). 사람이 누르는 버튼과 칸을 같은 길로 부르고, 창(JDialog) 안의 동작은 그 창이 부르는 함수를 그대로 부른다.
- 흐름 32개 가운데 26개는 모두 통과했다. 확인 345개 가운데 314개 통과, 31개 실패다.
- 이어지는 흐름은 앞 흐름의 단계를 다시 돈다. 보고서에서 "앞2"는 앞 흐름의 2단계라는 뜻이다. 그래서 같은 원인이 여러 흐름에 겹쳐 세어진다.
