# 수동 확인 목록

06 검사 줄 154개 가운데 흐름으로 확인하지 않는 43개다([user-flows.md](../user-flows.md) 커버리지 표). 프로토타입에는 저장, 알림, 트레이, 자동 실행, 하나만 실행, 날 바뀜이 없어서 이 목록은 실제 앱에서 확인한다. 결과 칸은 확인할 때 채운다.

## 1. 단위 검사로 확인(15개)

화면이 막는 값, 연도 경계, 실패 주입이라 흐름으로는 일어나지 않는다. 실제 앱의 JUnit 테스트로 만든다.

| 검사 | 왜 흐름 밖인가 | 결과 |
|---|---|---|
| T-DAY-3, T-DAY-4 | 23:59와 연말 새벽의 앱 날짜. 시계 경계 값 | |
| T-VAL-5, T-VAL-6 | 고정 일정의 시작 시각 없음, 09:05. 입력 창이 막는다 | |
| T-LVL-2, T-LVL-5, T-LVL-6, T-LVL-7 | 레벨 기준표의 경계 값 | |
| T-VIS-5 | 연말에서 새해로 이어지는 연속 접속 | |
| T-TT-4, T-TT-5 | 무리 안의 열 다시 쓰기, 같은 시각의 긴 일 먼저 | |
| T-SAVE-1~4 | 늘 실패하는 저장소를 끼워 넣어야 한다 | |
