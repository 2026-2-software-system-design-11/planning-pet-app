# 수동 확인 목록

06 검사 줄 158개 가운데 흐름으로 확인하지 않는 50개와, 흐름에 없는 화면 동작이다([user-flows.md](../user-flows.md) 커버리지 표). 프로토타입에는 저장, 알림, 트레이, 자동 실행, 하나만 실행, 날 바뀜이 없어서 이 목록은 실제 앱에서 확인한다. 결과 칸은 확인할 때 채운다.

## 1. 단위 검사로 확인(22개)

화면이 막는 값, 연도 경계, 실패 주입이거나 그 경우가 흐름에 없다. 실제 앱의 JUnit 테스트로 만든다.

| 검사 | 왜 흐름 밖인가 | 결과 |
|---|---|---|
| T-DAY-3, T-DAY-4 | 23:59와 연말 새벽의 앱 날짜. 시계 경계 값 | |
| T-VAL-5, T-VAL-6 | 고정 일정의 시작 시각 없음, 09:03. 입력 창이 막는다 | |
| T-VAL-9의 0, 27, 730 | 걸리는 시간 칸이 받지 않는다(D-38) | |
