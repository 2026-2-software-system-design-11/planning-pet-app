# 사용성 자동 규칙

`prototype/qa.sh`가 `QaRules`로 만든다. 손으로 고치지 않는다. 규칙과 까닭은 [blind/README.md](blind/README.md) 7절에 있다.

## 어긋남

| 규칙 | 어디 | 무엇 |
|---|---|---|
| 1 입력 보존 | 홈 글 칸 옆 "일정 추가" | 글을 쓰고 누르면 할 일 그대로, 글 남음, 창을 연다. 쓴 글이 쓰이지도 지워지지도 않는다 |
| 2 Enter와 옆 버튼 | 홈 글 칸과 "일정 추가" | Enter: 할 일 +1, 글 비움. 버튼: 할 일 그대로, 글 남음, 창을 연다 |
| 3 용어 | 시각 없는 할 일 | "시간 안 정한 할 일"(홈), "시각 없는 할 일"(일정관리), "시간이 안 정해진 할 일"(일정관리) |
| 3 용어 | 시작 시각 | "시작 시각"(일정 추가 창, 일정 수정 창), "시간 정하기"(홈), "시간 빼기"(시각 고치기 창) |
| 4 같은 이름 버튼의 자리 | ">" | 홈 위 오른쪽, 일정관리 위 왼쪽 |
| 4 같은 이름 버튼의 자리 | "삭제" | 홈 가운데 오른쪽, 일정관리 아래 오른쪽, 일정 수정 창 아래 왼쪽 |
| 4 같은 이름 버튼의 자리 | "수정" | 홈 가운데 오른쪽, 일정관리 아래 오른쪽 |
| 4 같은 이름 버튼의 자리 | "일정 추가" | 홈 아래 오른쪽, 일정관리 위 오른쪽 |
| 4 같은 이름 버튼의 자리 | "저장" | 일정 추가 창 아래 오른쪽, 일정 수정 창 아래 오른쪽, 시각 고치기 창 아래 가운데 |
| 4 같은 이름 버튼의 자리 | "취소" | 일정 추가 창 아래 오른쪽, 일정 수정 창 아래 오른쪽, 시각 고치기 창 아래 가운데, 자동 배치 결과 창 아래 왼쪽 |
